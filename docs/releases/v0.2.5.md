## MIDI Deck 0.2.5

Turn a MIDI controller into desktop controls while keeping its keyboard playable.

### Highlights
- Configure Global, user, and application profiles directly on the controller overview.
- Record keyboard shortcuts separately from MIDI Learn, including directional encoder shortcuts.
- Native macOS volume, mute, keyboard/media input, scrolling, and application detection.
- macOS permission checks run inside MIDI Deck and report actual keyboard delivery.
- MiniLab MkII LED feedback, both pad banks, pitch/modulation strips, and utility-control guidance.
- Corrected MiniLab encoder defaults and keyboard-channel-following input.
- Slower relative zoom, per-profile sensitivity, and the verified Affinity keypad zoom binding.
- Grayscale interface with the supplied full-color app icon.
- Configuration migration with backups and live routing diagnostics.

### Downloads
- **Windows x64:** `.exe` installer.
- **macOS Apple Silicon:** `mac-arm64.dmg` or `.zip`.
- **macOS Intel:** `mac-x64.dmg` or `.zip`.
- `SHA256SUMS.txt` contains checksums for the attached files.

### Setup notes
- Select your MIDI input in Settings, then choose a profile and click a control in Overview.
- On macOS, enable the installed MIDI Deck under **Privacy & Security → Accessibility** for keyboard-based actions. Use **Check permission again** to verify delivery.
- macOS builds are ad-hoc signed unless Developer ID credentials are configured; they are not notarized without Apple credentials. Windows installers are unsigned without a configured certificate.
- Automatic overlays and native banners are **off by default**, avoiding focus disruption on affected desktop/window-manager setups.
- Instruments are synthesized; custom SoundFonts and native low-latency audio remain future work.

See the [README](https://github.com/logno-dev/a-control/blob/v0.2.5/README.md) for controller setup, permissions, and current capabilities.
